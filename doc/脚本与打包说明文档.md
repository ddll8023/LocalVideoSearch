# VideoSearch 脚本与打包说明文档

## 一、整体架构

本项目采用 **Electron + Vue 3 + FastAPI** 三层桌面应用架构，以多进程方式协同运行：

| 层级 | 技术栈 | 端口 | 目录 |
| --- | --- | --- | --- |
| 桌面壳 | Electron ^31 | — | `electron/` |
| 前端 | Vue 3 + Vite ^6 | 4739 | `frontend/` |
| 后端 | Python FastAPI | 4740 | `backend/` |

运行时 Electron 主进程负责：创建窗口、管理 Python 后端子进程生命周期、提供 IPC 通信桥接。

---

## 二、开发脚本

项目根目录提供三个 `.bat` 批处理脚本用于开发调试：

### 2.1 start-frontend.bat — 独立启动前端

```
cd frontend && npm run dev
```

- 启动 Vite 开发服务器，监听 `http://127.0.0.1:4739`
- 适用于单独调试前端页面（需后端已运行）

### 2.2 start-backend.bat — 独立启动后端

```
uv run --directory backend uvicorn app.main:app --host 127.0.0.1 --port 4740 --reload
```

- 使用 `uv` 启动 FastAPI，带 `--reload` 热重载
- 适用于单独调试后端接口

### 2.3 start-dev.bat — 一键启动全栈开发

执行流程：

1. 在新窗口启动 Vite 前端开发服务器
2. 等待 3 秒
3. 在当前窗口启动 Electron

Electron 启动后自动连接 `http://127.0.0.1:4739`（Vite 开发服务器）并 spawn Python 后端子进程。

脚本通用约定：
- `chcp 65001` 设置 UTF-8 编码防止中文乱码
- 使用 `title` 设置窗口标题便于识别
- 结尾 `pause` 防止窗口闪退

## 三、Electron 主进程

主进程入口：`electron/main/index.js`

### 3.1 后端生命周期管理

```
应用启动 → spawn Python 子进程 → 轮询健康检查（最长 15s）→ 就绪后创建窗口
应用退出 → before-quit 拦截 → 停止后端子进程 → 真正退出
```

**启动后端**：

- 通过 `spawn` 启动 `python -m uvicorn app.main:app`
- 传入环境变量：`API_HOST`、`API_PORT`、`APP_DATA_DIR`、`PYTHONUNBUFFERED`
- 使用 `windowsHide: true` 隐藏控制台窗口
- stdout/stderr 重定向到 Electron 主进程控制台

**健康检查**：

- 请求 `GET /api/v1/health`，判断 `code === 0`
- 每 300ms 轮询一次，15 秒超时
- 超时则标记后端状态为 `error`

**优雅退出**：

- `before-quit` 事件拦截退出，先 `kill` 后端进程
- 等待 `exit` 事件或 3 秒超时后放行 `app.quit()`
- 防止产生孤儿 Python 进程

### 3.2 路径策略

主进程根据 `app.isPackaged` 区分开发与打包环境：

| 资源 | 开发模式 | 打包后 |
| --- | --- | --- |
| 后端目录 | `{PROJECT_ROOT}/backend` | `process.resourcesPath/backend` |
| Python 可执行文件 | `backend/.venv/Scripts/python.exe` | `process.resourcesPath/backend/backend.exe`（PyInstaller 单文件） |
| 前端页面 | `http://127.0.0.1:4739`（Vite） | `file://...frontend/dist/index.html` |
| 应用数据目录 | `app.getPath('appData')/VideoSearch` | 同上 |

环境变量 `VITE_DEV_SERVER_URL` 优先级最高（用于 electron-vite 等工具链集成）。

### 3.3 窗口配置

```
尺寸：1280 × 820（最小 1024 × 680）
边框：无边框（frame: false），自定义标题栏
背景色：#f7f7f2
```

### 3.4 IPC 通信

| 频道 | 方向 | 用途 |
| --- | --- | --- |
| `app:get-info` | 渲染→主 | 获取应用名、版本、平台 |
| `backend:get-base-url` | 渲染→主 | 获取后端 API 地址 |
| `backend:get-status` | 渲染→主 | 获取后端运行状态 |
| `window:minimize` | 渲染→主 | 最小化窗口 |
| `window:maximize` | 渲染→主 | 切换最大化/还原 |
| `window:close` | 渲染→主 | 关闭窗口 |
| `window:is-maximized` | 渲染→主 | 查询最大化状态 |
| `window:maximized-changed` | 主→渲染 | 最大化状态变更通知 |

### 3.5 安全配置

```
contextIsolation: true    — 上下文隔离
nodeIntegration: false    — 禁止渲染进程直接使用 Node
sandbox: false            — preload 脚本需要部分 Node 能力
```

通过 `contextBridge.exposeInMainWorld` 暴露有限的 `desktopApi` 接口给渲染进程。

## 四、前端构建（Vite）

配置文件：`frontend/vite.config.js`

| 配置项 | 值 | 说明 |
| --- | --- | --- |
| `base` | `'./'` | 相对路径，适配 Electron `file://` 协议 |
| `resolve.alias` | `@` → `src/` | 路径别名 |
| `server.host` | `127.0.0.1` | 仅本地访问 |
| `server.port` | `4739` | 前端开发服务器端口 |

构建命令：

```
npm run dev       → vite --mode development
npm run build     → vite build --mode production
npm run preview   → vite preview
```

## 五、打包配置

打包工具：**electron-builder ^24.13.3**

### 5.1 打包命令

```bash
npm run build:frontend   # 仅构建前端（Vite production）
npm run build:backend    # 仅打包后端（PyInstaller → backend/dist/backend.exe）
npm run dist:dir         # 构建前端 + 打包后端 + 生成解压即用目录（release/）
npm run dist:win         # 构建前端 + 打包后端 + 生成 NSIS 安装包（release/）
```

执行流程：

```
npm run build:frontend（Vite production 构建）
  ↓
npm run build:backend（PyInstaller 将 FastAPI 打包为单文件 exe）
  ↓
electron-builder --win（读取 package.json → build 配置）
  ↓
产物输出到 release/ 目录
```

### 5.2 打包产物

| 格式 | 说明 |
| --- | --- |
| `dir` | 解压即用目录，用于快速测试 |
| `nsis` | Windows 安装程序（.exe），用于分发 |

### 5.3 NSIS 安装程序配置

```
oneClick: false                      — 非静默安装，显示安装向导
allowToChangeInstallationDirectory   — 允许用户选择安装路径
createDesktopShortcut                — 创建桌面快捷方式
createStartMenuShortcut              — 创建开始菜单快捷方式
shortcutName: "VideoSearch"          — 快捷方式名称
```

### 5.4 资源嵌入（extraResources）

electron-builder 将以下内容作为额外资源嵌入到安装包：

| 源 | 打包目标 | 内容 |
| --- | --- | --- |
| `backend/dist/backend.exe` | `resources/backend/backend.exe` | PyInstaller 打包的后端单文件可执行程序 |
| `frontend/dist/` | `resources/frontend/dist/` | Vite 构建后的静态文件 |
| `resources/` | `resources/resources/` | 默认资源站配置 JSON |

**关键设计**：后端通过 PyInstaller 打包为独立 exe，不依赖 Python 环境，用户无需安装任何依赖即可运行应用。安装包体积相比整体打包 .venv 大幅缩小。

### 5.5 files 配置

```
files: ["package.json", "electron/**/*"]
```

仅将 Electron 主进程代码和 `package.json` 打入 `app.asar`，其余通过 `extraResources` 以原始目录结构释放。

## 六、依赖管理

| 生态 | 包管理器 | 配置文件 | 锁定文件 |
| --- | --- | --- | --- |
| Electron/前端 | npm | `package.json`（根目录 + `frontend/`） | `package-lock.json` |
| Python 后端 | uv | `backend/pyproject.toml` | `backend/uv.lock` |

后端依赖（`pyproject.toml`）：

```
fastapi >= 0.115.0
httpx >= 0.27.0
pydantic-settings >= 2.4.0
uvicorn[standard] >= 0.30.0
```

`[tool.uv] package = false` 表示后端不作为可安装的 Python 包，仅作为应用运行。

## 七、设计特点总结

| 维度 | 设计决策 |
| --- | --- |
| **架构** | Electron 壳 + PyInstaller 打包的 Python 后端 + Vue 前端，多进程协同 |
| **开发** | `.bat` 脚本一键启动，前后端可独立调试 |
| **打包** | PyInstaller 将后端打包为单文件 exe + electron-builder 打包 Electron，用户零依赖即可运行 |
| **进程管理** | Electron 主进程全权管理后端生命周期（spawn → 健康检查 → 优雅退出） |
| **安全** | 标准 Electron 安全实践（contextIsolation + contextBridge） |
| **目标平台** | 仅 Windows，使用 NSIS 安装程序 |
| **前端路由** | Hash 模式，兼容 `file://` 协议 |
| **数据目录** | 使用 `app.getPath('appData')/VideoSearch`，日志与运行时数据与安装目录分离 |
