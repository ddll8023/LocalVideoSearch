# VideoSearch 项目结构文档

## 一、技术栈

### 后端框架

| 技术 | 版本要求 | 作用 |
| --- | --- | --- |
| Python | >=3.11 | 后端运行语言 |
| FastAPI | >=0.115.0 | 后端 Web 框架，提供 RESTful API |
| Uvicorn | >=0.30.0 | ASGI 服务器，运行 FastAPI 应用 |
| Pydantic | 随 FastAPI 引入 | 数据模型定义、请求参数校验、响应序列化 |
| pydantic-settings | >=2.4.0 | 统一配置管理，支持环境变量和 .env 文件 |

### 数据存储

| 技术 | 版本要求 | 作用 |
| --- | --- | --- |
| SQLite | Python 内置 | 本地数据库文件（WAL 模式），存储搜索历史、收藏和播放记录 |
| SQLAlchemy | >=2.0 | ORM 框架，同步 Session 模式，管理数据模型与事务 |

### HTTP 客户端

| 技术 | 版本要求 | 作用 |
| --- | --- | --- |
| httpx | >=0.27.0 | 异步 HTTP 客户端，应用级共享实例复用连接池，请求第三方视频资源站 |

### 前端框架

| 技术 | 版本 | 作用 |
| --- | --- | --- |
| Vue 3 | ^3.5.13 | 前端 UI 框架，使用 Composition API 和 `<script setup>` |
| Pinia | ^3.0.1 | Vue 状态管理，管理搜索、资源站、视频播放、全局消息状态 |
| Vue Router | ^4.5.0 | 前端路由，支持懒加载和 Hash 模式 |

### 构建工具

| 技术 | 版本 | 作用 |
| --- | --- | --- |
| Vite | ^6.0.7 | 前端构建与开发服务器 |
| @vitejs/plugin-vue | ^5.2.1 | Vite 的 Vue 单文件组件支持插件 |

### 样式

| 技术 | 版本 | 作用 |
| --- | --- | --- |
| Tailwind CSS | ^3.4.17 | 原子化 CSS 框架，用于页面布局和组件样式 |
| PostCSS | ^8.5.1 | CSS 处理管道 |
| Autoprefixer | ^10.4.20 | 自动添加浏览器 CSS 前缀 |

### 前端其他组件

| 技术 | 版本 | 作用 |
| --- | --- | --- |
| Axios | ^1.7.9 | HTTP 请求库，统一封装后端 API 调用与错误分类 |
| ECharts | ^5.5.1 | 数据可视化图表库，用于监控页的搜索趋势柱状图和热门关键词条形图（按需引入） |
| Artplayer | ^5.4.0 | 视频播放器组件，提供倍速、快捷键、画中画、全屏等播放控制 |
| HLS.js | ^1.5.20 | m3u8 流媒体播放库，配合 Artplayer 播放 HLS 协议视频 |
| FontAwesome 6 | ^6.7.2 | 图标库，提供全局统一的 SVG 图标（solid + regular） |

### 桌面端

| 技术 | 版本 | 作用 |
| --- | --- | --- |
| Electron | ^31.7.7 | 桌面端框架，管理窗口和后端进程生命周期，启动失败时展示原生错误对话框 |
| electron-builder | ^24.13.3 | Electron 打包工具，生成 Windows 安装程序 |

### 包管理

| 技术 | 作用 |
| --- | --- |
| uv | Python 包管理工具，管理后端虚拟环境和依赖 |
| npm | Node.js 包管理工具，管理前端和 Electron 依赖 |

### 依赖配置文件

| 文件 | 说明 |
| --- | --- |
| `package.json`（根目录） | Electron 主项目依赖（electron、electron-builder）和打包配置 |
| `package-lock.json`（根目录） | Electron 主项目依赖锁定 |
| `backend/pyproject.toml` | 后端 Python 依赖声明（fastapi、httpx、pydantic-settings、sqlalchemy、uvicorn），使用 uv 管理 |
| `backend/uv.lock` | 后端 uv 依赖锁定 |
| `backend/entry.py` | PyInstaller 打包入口脚本，用于 Electron 直接启动后端 exe |
| `frontend/package.json` | 前端依赖声明（vue、pinia、vue-router、axios、echarts、artplayer、hls.js、tailwindcss 等） |
| `frontend/package-lock.json` | 前端依赖锁定 |
