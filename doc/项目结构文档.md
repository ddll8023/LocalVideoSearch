# VideoSearch 项目结构文档

## 一、技术栈

### 后端框架

| 技术 | 版本要求 | 作用 |
| --- | --- | --- |
| Python | >=3.11 | 后端运行语言 |
| FastAPI | >=0.115.0 | 后端 Web 框架，提供 RESTful API |
| Uvicorn | >=0.30.0 | ASGI 服务器，运行 FastAPI 应用 |
| Pydantic | 随 FastAPI 引入 | 数据模型定义、请求参数校验、响应序列化 |
| pydantic-settings | >=2.4.0 | 统一配置管理，支持环境变量和 .env 文件 |

### HTTP 客户端

| 技术 | 版本要求 | 作用 |
| --- | --- | --- |
| httpx | >=0.27.0 | 异步 HTTP 客户端，用于请求第三方视频资源站 |

### 前端框架

| 技术 | 版本 | 作用 |
| --- | --- | --- |
| Vue 3 | ^3.5.13 | 前端 UI 框架，使用 Composition API 和 `<script setup>` |
| Pinia | ^3.0.1 | Vue 状态管理，管理搜索、资源站、视频播放状态 |
| Vue Router | ^4.5.0 | 前端路由，支持懒加载和 History 模式 |

### 构建工具

| 技术 | 版本 | 作用 |
| --- | --- | --- |
| Vite | ^6.0.7 | 前端构建与开发服务器 |
| @vitejs/plugin-vue | ^5.2.1 | Vite 的 Vue 单文件组件支持插件 |

### 样式

| 技术 | 版本 | 作用 |
| --- | --- | --- |
| Tailwind CSS | ^3.4.17 | 原子化 CSS 框架，用于页面布局和组件样式 |
| PostCSS | ^8.5.1 | CSS 处理管道 |
| Autoprefixer | ^10.4.20 | 自动添加浏览器 CSS 前缀 |

### 前端其他组件

| 技术 | 版本 | 作用 |
| --- | --- | --- |
| Axios | ^1.7.9 | HTTP 请求库，统一封装后端 API 调用 |
| ECharts | ^5.5.1 | 数据可视化图表库，用于监控页面的趋势图和统计图 |
| HLS.js | ^1.5.20 | m3u8 流媒体播放库，用于 HLS 协议视频播放 |
| FontAwesome 6 | ^6.7.2 | 图标库，提供全局统一的 SVG 图标 |

### 桌面端

| 技术 | 版本 | 作用 |
| --- | --- | --- |
| Electron | ^31.7.7 | 桌面端框架，管理窗口和后端进程生命周期 |
| electron-builder | ^24.13.3 | Electron 打包工具，生成 Windows 安装程序 |

### 包管理

| 技术 | 作用 |
| --- | --- |
| uv | Python 包管理工具，管理后端虚拟环境和依赖 |
| npm | Node.js 包管理工具，管理前端和 Electron 依赖 |

## 二、项目结构

```text
VideoSearch/
├── .gitignore                                    # Git 忽略规则，排除 .venv、node_modules、dist、release 等目录
├── README.md                                     # 项目说明文档，包含技术栈、功能说明和部署指南
├── package.json                                  # Electron 主项目配置，定义打包脚本和 electron-builder 配置
├── package-lock.json                             # Electron 主项目依赖锁定文件
├── start-backend.bat                             # 开发辅助脚本，独立启动 FastAPI 后端（端口 4740）
├── start-dev.bat                                 # 开发辅助脚本，同时启动 Vite 前端和 Electron
├── start-frontend.bat                            # 开发辅助脚本，启动 Vite 前端开发服务器（端口 4739）
│
├── backend/                                      # Python 后端
│   ├── pyproject.toml                            # 后端依赖声明和项目元数据
│   ├── uv.lock                                   # uv 依赖锁定文件
│   └── app/
│       ├── main.py                               # FastAPI 应用入口，配置 CORS、生命周期、全局异常处理
│       ├── api/
│       │   └── v1/
│       │       ├── router.py                     # API v1 路由聚合，统一挂载 /api/v1 前缀下所有子路由
│       │       ├── health.py                     # 健康检查 API，提供后端运行状态和配置信息
│       │       ├── resources.py                  # 资源站 API，提供列表查询、详情、启停切换和连接测试
│       │       ├── videos.py                     # 视频 API，提供单站点搜索和详情查询
│       │       ├── logs.py                       # 日志 API，提供系统日志查询、统计和清理
│       │       └── monitor.py                    # 监控 API，提供仪表板概览、活跃用户、搜索统计、趋势和热门关键词
│       ├── constants/
│       │       ├── resources.py                  # 资源站模块常量，定义连接测试提示信息和配置读写错误信息
│       │       └── videos.py                     # 视频模块常量，定义过滤类型名称和 HTTP 请求头
│       ├── core/
│       │       ├── config.py                     # 应用统一配置，管理端口、数据目录、资源站路径、日志路径等
│       │       └── logging.py                    # JSON Lines 日志系统，包含日志格式化器、请求日志记录器和日志初始化
│       ├── schemas/
│       │       ├── response.py                   # 通用响应模型，定义 ApiResponse、PaginatedResponse、ErrorCode、success/error 构造函数
│       │       ├── health.py                     # 健康检查响应模型，包含应用名、环境、端口和状态字段
│       │       ├── resources.py                  # 资源站模型，定义站点信息、统计数据、启停切换和连接测试响应结构
│       │       ├── videos.py                     # 视频模型，定义搜索请求/响应、详情请求/响应、播放源和过滤统计结构
│       │       ├── logs.py                       # 日志模型，定义日志查询请求、日志列表项、统计和清理响应结构
│       │       └── monitor.py                    # 监控模型，定义概览、活跃用户、搜索统计、系统健康、趋势、站点性能和热门关键词响应结构
│       ├── services/
│       │       ├── health.py                     # 健康检查服务，组装应用配置信息返回运行状态
│       │       ├── resources.py                  # 资源站服务，实现配置文件读写、站点启停、连接测试和启用校验
│       │       ├── videos.py                     # 视频服务，实现单站点搜索、详情定位、第三方请求和异常转换
│       │       ├── logs.py                       # 日志服务，实现 JSON Lines 日志文件读取、过滤、分页、统计和清理
│       │       └── monitor.py                    # 监控服务，基于日志数据聚合仪表板概览、趋势、站点性能和热门关键词
│       └── utils/
│               ├── exception.py                  # 业务异常类 ServiceException，携带错误码和错误消息
│               ├── http_client.py                # 统一异步 HTTP 请求工具，封装 httpx 调用并记录请求日志
│               └── video_mapper.py               # 视频字段映射工具，实现第三方响应字段转换、播放源解析和视频列表提取
│
├── electron/                                     # Electron 桌面端
│   ├── main/
│   │   └── index.js                              # 主进程，管理窗口创建、FastAPI 子进程启停、健康检查轮询和 IPC 处理
│   └── preload/
│       └── index.js                              # 预加载脚本，通过 contextBridge 暴露 desktopApi（应用信息、后端地址、后端状态）
│
├── frontend/                                     # Vue 3 前端
│   ├── index.html                                # 前端 HTML 入口，挂载 Vue 应用到 #app
│   ├── package.json                              # 前端依赖声明和脚本配置
│   ├── package-lock.json                         # 前端依赖锁定文件
│   ├── vite.config.js                            # Vite 配置，设置路径别名 @/ 和开发服务器端口 4739
│   ├── postcss.config.js                         # PostCSS 配置，启用 Tailwind CSS 和 Autoprefixer 插件
│   ├── tailwind.config.js                        # Tailwind 配置，定义自定义颜色（ink/canvas/primary/accent）和字体
│   └── src/
│       ├── main.js                               # Vue 应用入口，初始化 Pinia、Router、FontAwesome 图标注册
│       ├── App.vue                               # 应用根组件，提供顶部导航栏（搜索/设置/监控/日志）和 RouterView 出口
│       ├── api/
│       │   ├── index.js                          # API 统一导出入口，聚合 logs、monitor、resources、videos 模块
│       │   ├── logs.js                           # 日志 API 调用，封装日志查询、统计和清理接口
│       │   ├── monitor.js                        # 监控 API 调用，封装概览、活跃用户、搜索统计、站点性能、趋势和热门关键词接口
│       │   ├── resources.js                      # 资源站 API 调用，封装站点列表、详情、启停切换和连接测试接口
│       │   └── videos.js                         # 视频 API 调用，封装视频搜索和详情查询接口
│       ├── assets/
│       │   └── styles/
│       │       └── main.css                      # 全局样式，定义 Tailwind 基础层和公共组件类（surface、toolbar-button、primary-button、field-input）
│       ├── components/
│       │   ├── base/
│       │   │   ├── AppAlert.vue                  # 通用提示组件，支持 error/warning/info/success 四种类型和重试按钮
│       │   │   ├── AppEmptyState.vue             # 通用空状态组件，展示图标、标题、描述和插槽内容
│       │   │   ├── AppLoadingState.vue            # 通用加载状态组件，展示旋转图标和加载文字
│       │   │   └── AppPagination.vue             # 通用分页组件，提供上一页/下一页按钮和分页信息展示
│       │   └── business/
│       │       └── VideoResultCard.vue           # 视频搜索结果卡片组件，展示缩略图、标题、类型和状态信息
│       ├── router/
│       │   └── index.js                          # 路由配置，定义首页、设置、详情、播放、管理入口、监控和日志七个路由（全部懒加载）
│       ├── stores/
│       │   ├── index.js                          # Store 统一导出入口，聚合 resources、search、video 三个 Store
│       │   ├── resources.js                      # 资源站 Store，管理站点列表、启停切换、单站测试、批量测试和统计状态
│       │   ├── search.js                         # 搜索 Store，管理搜索关键词、多站点并发搜索结果、Tab 切换、分页和 localStorage 缓存
│       │   └── video.js                          # 视频 Store，管理当前视频详情、播放源分组、剧集选择和播放状态
│       ├── utils/
│       │   ├── request.js                        # Axios 统一请求层，支持 Electron preload 注入后端地址，统一响应拦截和错误处理
│       │   └── format.js                         # 格式化工具函数，提供耗时格式化和数字格式化
│       └── views/
│           ├── admin/
│           │   ├── Dashboard.vue                 # 管理入口页，提供系统监控、系统日志和资源站设置三个功能入口卡片
│           │   ├── SystemLogs.vue                # 系统日志页，支持日志统计展示、类型/级别/关键词筛选、分页浏览、详情弹窗和日志清理
│           │   └── SystemMonitor.vue             # 系统监控页，支持概览统计、活跃趋势图、站点性能表格、热门关键词和 30 秒自动刷新
│           └── user/
│               ├── Home.vue                      # 搜索首页，提供搜索框、多资源站并发搜索、Tab 结果展示、单站分页和 2 小时缓存恢复
│               ├── Settings.vue                  # 资源站设置页，展示站点统计、单站启停、单站连接测试和批量测试已启用站点
│               ├── VideoDetail.vue               # 视频详情页，展示视频元信息（海报、标题、演员等）和按格式分组的播放源剧集入口
│               └── VideoPlayer.vue               # 视频播放页，支持 HLS.js 流媒体播放和普通视频 URL 播放，右侧显示剧集列表和切换
│
├── resources/                                    # 默认资源文件
│   └── resource_sites.json                      # 默认资源站配置文件，包含 16 个视频资源站的 API 地址和参数配置
│
├── doc/                                          # 项目文档
│   └── 开发设计文档.md                            # 开发设计文档，记录架构设计、接口规范和开发阶段计划
│
└── 规范文档/                                      # 编码规范
    ├── 后端规范文档.md                             # 后端 Python/FastAPI 编码规范
    └── 前端规范文档.md                             # 前端 Vue 3/Tailwind CSS 编码规范
```

### 依赖配置文件说明

| 文件 | 说明 |
| --- | --- |
| `package.json`（根目录） | Electron 主项目依赖（electron、electron-builder）和打包配置 |
| `package-lock.json`（根目录） | Electron 主项目依赖锁定 |
| `backend/pyproject.toml` | 后端 Python 依赖声明（fastapi、httpx、pydantic-settings、uvicorn），使用 uv 管理 |
| `backend/uv.lock` | 后端 uv 依赖锁定 |
| `frontend/package.json` | 前端依赖声明（vue、pinia、vue-router、axios、echarts、hls.js、tailwindcss 等） |
| `frontend/package-lock.json` | 前端依赖锁定 |
